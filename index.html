What it does

Browser operations, without a local Chromium install.

The public interface exposes direct browser controls and an optional native Playwright MCP relay. The relay is not yet a drop-in replacement for every native MCP tool.

01

Interact with real pages

Navigate, inspect HTML, click, type, evaluate and capture screenshots in cloud Chromium.

02

Connect AI coding agents

Standard MCP JSON-RPC over HTTPS, with Bearer authorization and separate conversation IDs for independent sessions.

03

Use native Playwright tools

A sandbox-local Microsoft Playwright MCP server makes extra tools discoverable through a relay, including accessibility snapshots.

Get connected

Two headers. One browser endpoint.

Deploy the repository into your own EdgeOne account, configure a strong MCP_BEARER_TOKEN, and supply your distinct client conversation ID. Never commit actual tokens.

Codex · config.toml
[mcp_servers.edgeone_browser]
url = "https://YOUR-DEPLOYMENT/mcp"
http_headers = { "Authorization" = "Bearer <TOKEN>", "makers-conversation-id" = "codex-unique" }
OpenCode · opencode.json
{
  "mcp": {
    "edgeone_browser": {
      "type": "remote",
      "url": "https://YOUR-DEPLOYMENT/mcp",
      "headers": {
        "Authorization": "Bearer <TOKEN>",
        "makers-conversation-id": "opencode-unique"
      },
      "enabled": true
    }
  }
}

Adapt the snippets to your installed agent version and preserve its existing configuration. For deployment and a curl example, see the README.

Known boundaries

Built for development workflows, not anonymous browsing.

Short-lived instances

One sandbox stayed responsive for at least 56 minutes in testing. Lifecycle, account quotas and exact free usage are platform-controlled.

Native relay overhead

External CDP WebSocket was rejected by the platform, so native Playwright operations pass through a sandbox-internal relay and may add latency.

Private single-tenant service

Conversation IDs are client-supplied routing keys, not independent credentials. Treat the same Bearer token as one trust domain.

Security note: Current PoC tools include privileged sandbox command execution and unsafe browser code paths. Use only with trusted agents and controlled test targets until the default tool surface is hardened. Never expose your Bearer token or a CDP session URL.
